# Інформаційна система супроводу дипломного проектування

**Кременчуцький національний університет імені Михайла Остроградського (КрНУ)**

## 📖 Про проект

Цей репозиторій містить вихідний код програмного комплексу для автоматизації процесу виконання випускних кваліфікаційних робіт. Система розроблена для впорядкування взаємодії між студентами та керівниками, а також для автоматизації рутинних процесів створення документації.

### Архітектура рішення
Система реалізована як **два незалежні веб-застосунки**, що інтегровані через спільний контекст даних (Shared Database):

1. **Система контролю (Control System)** — основна точка входу. Забезпечує управління етапами, ролями та моніторинг прогресу.
2. **Підсистема генерації (Document Subsystem)** — спеціалізований веб-ресурс для формування друкованих документів.

Користувач працює в основній системі, а за необхідності сформувати документ перенаправляється до підсистеми генерації, яка використовує ті самі дані для створення файлів.

## 🏗 Структура репозиторію

Проект розділено на зони відповідальності між розробниками:

### 1. Модуль контролю та управління (Control System)
*Розробник: **Олександра Куктенко***

Основний веб-ресурс для адміністрування навчального процесу.
* 📂 **`diplomaControlSystem.Server`** — Backend (.NET / ASP.NET Core). Реалізує бізнес-логіку трекінгу завдань та управління користувачами.
* 📂 **`diplomaControlSystem.Client`** — Frontend. Інтерфейс користувача для відображення прогресу та кабінету.

### 2. Модуль генерації документів (Document Generation)
*Розробник: **Дмитро Бутник***

Окремий веб-сервіс, сфокусований на роботі з шаблонами та файлами.
* 📂 **`documentGenerationSubsystem.Server`** — Backend (.NET / ASP.NET Core). Логіка заповнення шаблонів даними зі спільної БД.
* 📂 **`documentGenerationSubsystem.Client`** — Frontend. Інтерфейс для налаштування параметрів документу та його завантаження.

## 🛠 Технологічний стек

* **Платформа:** .NET 10 (ASP.NET Core Web API).
* **База даних:** Спільна реляційна база даних (PostgreSQL) для обох підсистем.
* **ORM:** Entity Framework Core.
* **Frontend:** React.
